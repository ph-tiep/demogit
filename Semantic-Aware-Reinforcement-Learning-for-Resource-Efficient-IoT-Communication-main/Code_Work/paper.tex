\begin{abstract}
Internet of Things (IoT) networks face critical challenges in
semantic communication efficiency and resource-constrained
optimization. Existing approaches rely on hand-crafted feature
engineering, static classifiers, and single-agent reinforcement
learning, which fail to capture the dynamic, cooperative nature
of multi-node IoT environments. This paper proposes a novel
three-component framework: (1) a Variational Autoencoder (VAE)
for unsupervised semantic feature compression from raw sensor
data; (2) a Digital Twin driven by an Extended Kalman Filter
(EKF) for continuous network state estimation and anomaly
detection, replacing traditional Random Forest and Isolation
Forest classifiers; and (3) a Multi-Agent Deep Reinforcement
Learning (MADRL) system augmented by a Graph Attention Network
(GAT) that models inter-node communication topology for
cooperative resource allocation. Experiments on three
heterogeneous IoT datasets—Sigfox Antwerp (14,377 samples,
84 base stations), LoRaWAN Italy (190,502 samples, 8 sensor
nodes), and Indoor WiFi positioning (1,100 samples, 10 access
points)—demonstrate that the proposed framework achieves
Digital Twin quality AUC scores of 0.838, 0.908, and 0.995
respectively, while MADRL+GAT agents improve cumulative
network reward by up to 48.3\% over 50 training episodes.
\end{abstract}

\begin{IEEEkeywords}
Internet of Things, Semantic Communication, Variational
Autoencoder, Digital Twin, Extended Kalman Filter, Multi-Agent

Efficiency.

\section{Introduction}
\label{sec:intro}

The rapid proliferation of IoT devices has created unprecedented
demand for efficient, adaptive wireless communication systems.
Modern IoT deployments span diverse environments—from outdoor
wide-area networks (WANs) using Sigfox and LoRaWAN protocols
to indoor WiFi-based positioning systems—each with distinct
channel characteristics, energy constraints, and quality-of-service
(QoS) requirements \cite{ref_iot_survey}.

\textbf{Limitations of existing approaches.}
Conventional IoT communication frameworks suffer from three
fundamental limitations. First, semantic feature extraction relies
on domain-specific, hand-crafted features (e.g., mean RSSI,
active base station count) that fail to capture higher-order
statistical dependencies in raw sensor data \cite{ref_semantic}.
Second, network quality classification and anomaly detection are
typically handled by static machine learning models (Random Forest,
Isolation Forest) trained offline, which cannot adapt to
non-stationary channel dynamics \cite{ref_rf_iot}. Third,
resource allocation is optimized by single-agent Deep Q-Networks
(DQN) that ignore the cooperative structure of multi-node IoT
deployments and the graph topology of communication networks
\cite{ref_dqn_iot}.

\textbf{Proposed contributions.}
This paper addresses the above limitations through the following
contributions:
\begin{enumerate}
  \item A \textbf{VAE-based semantic encoder} that learns
        compressed latent representations from raw multi-dimensional
        RSSI measurements, replacing hand-crafted feature pipelines.
  \item A \textbf{Digital Twin with EKF} that continuously tracks
        network state, classifies link quality, and detects anomalies
        through statistically principled innovation testing—without
        requiring labeled training data.
  \item A \textbf{MADRL+GAT framework} where multiple IoT agents
        cooperatively optimize transmission resource allocation,
        with the GAT capturing physical network topology for
        spatially-aware decision making.
\end{enumerate}

The remainder of this paper is organized as follows. Section~\ref{sec:related}
reviews related work. Section~\ref{sec:framework} describes the
proposed framework. Section~\ref{sec:experiments} presents the
experimental setup. Section~\ref{sec:results} analyzes results.
Section~\ref{sec:conclusion} concludes the paper.

\section{Related Work}
\label{sec:related}

\subsection{Semantic Communication in IoT}
Semantic communication systems aim to transmit the meaning of
data rather than raw bits \cite{ref_semantic2}. Recent works have
applied deep learning to extract semantic features for wireless
channel compression \cite{ref_deepjscc}. However, these approaches
require supervised training with task-specific labels, limiting
generalization across heterogeneous IoT environments.

\subsection{Digital Twins for Network Management}
Digital Twin (DT) technology has emerged as a promising paradigm
for real-time network monitoring \cite{ref_dt_network}. Prior
work on DT-based IoT management employs physics-based simulation
models \cite{ref_dt_iot}, but few works integrate Kalman
filtering for adaptive state estimation under measurement noise.
The EKF has been successfully applied in navigation and tracking
\cite{ref_ekf}, yet its application to IoT network state
estimation and anomaly detection remains underexplored.

\subsection{Multi-Agent Reinforcement Learning for IoT}
MARL approaches have demonstrated superior performance over
single-agent methods in cooperative wireless resource management
\cite{ref_marl_wireless}. Graph Neural Networks (GNNs) have
been incorporated into MARL to exploit communication graph
structure \cite{ref_gnn_marl}. GAT-based approaches
\cite{ref_gat} enable learned, attention-weighted aggregation
over network topologies. However, the integration of MARL+GAT
with semantic VAE encoding and Digital Twin state estimation
for IoT resource allocation has not been previously investigated.

\subsection{Variational Autoencoder for Semantic Compression}
\label{subsec:vae}

Let $\mathbf{x} \in \mathbb{R}^D$ denote the raw observation
vector (e.g., $D = 84$ RSSI values for Sigfox). The VAE learns
a latent representation $\mathbf{z} \in \mathbb{R}^L$ ($L \ll D$)
by maximizing the Evidence Lower Bound (ELBO):
\begin{equation}
  \mathcal{L}_{\text{VAE}} = \mathbb{E}_{q_\phi(\mathbf{z}|\mathbf{x})}
  [\log p_\theta(\mathbf{x}|\mathbf{z})]
  - \beta\, D_{\text{KL}}(q_\phi(\mathbf{z}|\mathbf{x}) \| p(\mathbf{z}))
  \label{eq:vae}
\end{equation}
where $q_\phi(\mathbf{z}|\mathbf{x}) = \mathcal{N}(\boldsymbol{\mu},
\text{diag}(\boldsymbol{\sigma}^2))$ is the approximate posterior
parameterized by the encoder, $p(\mathbf{z}) = \mathcal{N}(\mathbf{0},
\mathbf{I})$ is the standard normal prior, and $\beta$ controls
the KL regularization strength.

The encoder architecture is:
$\mathbb{R}^D \xrightarrow{\text{FC+BN+ReLU}} \mathbb{R}^{H}
\xrightarrow{\text{FC+BN+ReLU}} \mathbb{R}^{H/2}
\xrightarrow{} (\boldsymbol{\mu}, \log\boldsymbol{\sigma}^2) \in \mathbb{R}^{L}$

At inference, the latent code is the deterministic mean
$\mathbf{z} = \boldsymbol{\mu}$, providing a compressed semantic
state representation for downstream components.

\subsection{Digital Twin with Extended Kalman Filter}
\label{subsec:dt}

The Digital Twin maintains a virtual model of the IoT network
state $\mathbf{x}_t = [\bar{r}_t,\, n_t]^\top$, where $\bar{r}_t$
is the estimated mean RSSI and $n_t$ is the estimated number of
active base stations.

\textbf{Process model:}
\begin{equation}
  \mathbf{x}_{t+1} = \mathbf{F}\mathbf{x}_t + \mathbf{w}_t,\quad
  \mathbf{w}_t \sim \mathcal{N}(\mathbf{0}, \mathbf{Q})
  \label{eq:ekf_process}
\end{equation}

\textbf{Observation model:}
\begin{equation}
  \mathbf{z}_t = \mathbf{H}\mathbf{x}_t + \mathbf{v}_t,\quad
  \mathbf{v}_t \sim \mathcal{N}(\mathbf{0}, \mathbf{R})
  \label{eq:ekf_obs}
\end{equation}
where $\mathbf{F} = \mathbf{H} = \mathbf{I}_2$ (constant-state
model with direct observation).

The EKF predict-update cycle produces the innovation vector
$\mathbf{y}_t = \mathbf{z}_t - \mathbf{H}\hat{\mathbf{x}}_{t|t-1}$
and its covariance $\mathbf{S}_t$. The Normalized Innovation
Squared (NIS) statistic:
\begin{equation}
  \text{NIS}_t = \mathbf{y}_t^\top \mathbf{S}_t^{-1} \mathbf{y}_t
  \sim \chi^2(m)
  \label{eq:nis}
\end{equation}
follows a chi-squared distribution under nominal conditions.
Observations with $\text{NIS}_t > \chi^2_{0.95}(m)$ are
flagged as anomalies. Network quality is classified as:
\begin{equation}
  \hat{y}_t = \mathbf{1}[\hat{r}_t > \tau_r]
  \label{eq:quality}
\end{equation}
where $\tau_r$ is a dataset-specific RSSI threshold.

\subsection{MADRL with Graph Attention Network}
\label{subsec:madrl}

\textbf{GAT encoder.} Let $\mathcal{G} = (\mathcal{V}, \mathcal{E})$
be the IoT network graph where nodes $\mathcal{V}$ represent agents
(base stations or sensor nodes) and edges $\mathcal{E}$ represent
communication links. The GAT computes attention-weighted aggregation:
\begin{equation}
  \alpha_{ij} = \frac{\exp(\text{LeakyReLU}(\mathbf{a}^\top
  [\mathbf{W}\mathbf{h}_i \| \mathbf{W}\mathbf{h}_j]))}
  {\sum_{k \in \mathcal{N}(i)} \exp(\text{LeakyReLU}(\mathbf{a}^\top
  [\mathbf{W}\mathbf{h}_i \| \mathbf{W}\mathbf{h}_k]))}
  \label{eq:gat_attn}
\end{equation}
\begin{equation}
  \mathbf{h}_i' = \sigma\left(\sum_{j \in \mathcal{N}(i)}
  \alpha_{ij} \mathbf{W}\mathbf{h}_j\right)
  \label{eq:gat_agg}
\end{equation}

\textbf{Cooperative reward.} Each agent $i$ selects an action
$a_i \in \{0,1,2,3,4\}$ representing transmission resource level.
The shared cooperative reward is:
\begin{equation}
  r_t = \underbrace{\tilde{r}_t \cdot 5}_{\text{quality}}
      + \underbrace{\min\!\left(\tfrac{n_t}{20}, 1\right) \cdot 2}_{\text{connectivity}}
      - \underbrace{\frac{\bar{a}_t}{4} \cdot 3}_{\text{resource cost}}
      + \underbrace{\max\!\left(0, 1 - \tfrac{\sigma_a}{2}\right)}_{\text{cooperation}}
  \label{eq:reward}
\end{equation}
where $\tilde{r}_t \in [0,1]$ is the normalized RSSI,
$\bar{a}_t = \frac{1}{N}\sum_i a_i$ is the mean action,
and $\sigma_a$ is the action standard deviation.
This reward explicitly models the \emph{energy-quality trade-off}:
higher resource allocation ($\bar{a}_t$) improves connectivity
but incurs a resource cost, while agent coordination ($\sigma_a \to 0$)
yields a cooperation bonus.

\textbf{Training.} We employ centralized training with decentralized
execution (CTDE). The shared Q-network $Q(\mathbf{s}_t, \mathbf{a},
\mathbf{A}; \theta)$ is updated via:
\begin{equation}
  \mathcal{L}(\theta) = \mathbb{E}\left[
  \left(r_t + \gamma \max_{\mathbf{a}'} Q(\mathbf{s}_{t+1},
  \mathbf{a}', \mathbf{A}; \theta^-) - Q(\mathbf{s}_t, \mathbf{a}_t,
  \mathbf{A}; \theta)\right)^2\right]
  \label{eq:dqn_loss}
\end{equation}

\textbf{Quality classification.} The proposed DT-EKF achieves
quality AUC scores of 0.838, 0.908, and 0.995 on Antwerp,
LoRaWAN, and Indoor datasets respectively (Fig.~\ref{fig:roc}).
While the accuracy of the DT is lower than RF (0.767 vs. 1.000
on Antwerp), this comparison is not entirely fair: the RF
baseline achieves perfect accuracy because its training labels
are directly derived from the RSSI features used in training
(\emph{label leakage}), rendering the comparison degenerate.
The DT-EKF, by contrast, operates without any labeled training
data, making real-time quality decisions based solely on EKF
state estimates.

\textbf{Anomaly detection.} The DT-EKF achieves anomaly
detection AUC of 0.835, 0.916, and 0.778 using only the
Normalized Innovation Squared (NIS) statistic—a principled
chi-squared test that requires no anomaly labels. This
demonstrates that the Digital Twin can identify abnormal
network behavior through statistical deviation from the
predicted state, complementing traditional Isolation Forest
approaches.

\textbf{State estimation accuracy.} The EKF RSSI estimation
RMSE is 4.57 dBm on Antwerp and 0.92 dBm on Indoor, confirming
that the Digital Twin maintains an accurate virtual representation
of the physical network state throughout operation.

Fig.~\ref{fig:madrl_rewards} demonstrates clear, monotonic
reward improvement across all three datasets throughout the
50-episode training process. This confirms that the MADRL+GAT
agents successfully learn cooperative resource allocation
policies through experience.

\textbf{Antwerp (Sigfox)} exhibits the highest relative
improvement of 48.3\% from episode 1 to episode 50.
The outdoor, multi-base-station environment benefits most from
cooperative action coordination, where GAT attention weights
allow agents to differentiate between strongly and weakly
correlated base stations when allocating transmission resources.

\textbf{LoRaWAN (Italy)} shows 31.5\% improvement. In this
agricultural sensor network with a single gateway, the
cooperative reward encourages agents to coordinate their
transmission power levels to avoid channel collisions and
reduce energy consumption.

\textbf{Indoor (WiFi)} achieves 24.4\% improvement. The fully
connected GAT topology (all 10 APs visible to each agent) allows
fine-grained coordination between access points, resulting in
the highest absolute evaluation reward of 3,064 due to the
favorable indoor channel conditions.

The evaluation reward consistently exceeds the final training
episode reward on all datasets (e.g., 1,916 vs. 1,699 on
Antwerp), indicating that the trained policy generalizes well
and benefits from greedy exploitation once exploration
($\varepsilon$-greedy) is removed.

\section{Discussion}
\label{sec:discussion}

\textbf{DT accuracy vs. AUC.}
The accuracy of the Digital Twin quality classifier is lower
than the RF baseline (0.767 vs. 1.000 on Antwerp). This is
expected: the DT uses a fixed RSSI threshold for binary
classification, while the RF is trained with exact labels from
the same threshold, effectively memorizing the decision boundary.
AUC is the appropriate comparison metric as it is
threshold-independent and measures discriminative ability.

\textbf{Limitations.} The MADRL environment is a replay-based
simulation rather than a physics-based channel model, meaning
agent actions do not alter observed RSSI values. While this is
a simplification, it allows evaluation of cooperative policy
learning under realistic channel statistics. Future work will
integrate a channel simulation model to enable action-conditioned
state transitions.

% ============================================================
\section{Conclusion}
\label{sec:conclusion}

This paper proposed and evaluated a novel IoT communication
framework integrating three complementary components: VAE-based
semantic compression, EKF-driven Digital Twin state estimation,
and MADRL+GAT cooperative resource allocation. Experiments on
three heterogeneous IoT datasets demonstrated that:
\begin{itemize}
  \item The VAE achieves compact semantic representations with
        reconstruction MSE as low as 0.0082, enabling a
        5.3$\times$ compression of 84-dimensional RSSI data.
  \item The Digital Twin achieves quality classification AUC
        of 0.838--0.995 without labeled training data, using only
        EKF state estimation and statistical anomaly testing.
  \item MADRL+GAT agents learn cooperative resource allocation
        policies with 24.4--48.3\% reward improvement over 50
        training episodes, consistently outperforming the
        single-agent DQN baseline.
\end{itemize}

Future work will extend the framework with: (1) physics-based
channel simulation for action-conditioned environment dynamics;
(2) transfer learning across heterogeneous IoT protocols;
and (3) federated training for privacy-preserving multi-operator
deployment.
